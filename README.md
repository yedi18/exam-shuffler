# מערבל מבחנים 🔀

כלי אוטומטי לערבול סדר התשובות במבחני בחירה בעברית בפורמט PDF.
מיועד למורים שרוצים ליצור גרסאות שונות של אותו מבחן — כל גרסה עם סדר תשובות אחר.

---

## איך זה עובד

1. מזהה אוטומטית את מבנה המבחן — שאלות בפורמט "שאלה מספר N" ותשובות עם אותיות א/ב/ג/ד/ה
2. מערבל את **תוכן** התשובות בכל שאלה — האותיות עצמן נשארות במקומן בדף
3. מחליף את המחרוזת `0000` שבכותרת המבחן בקוד 4 ספרות ייחודי הנגזר מהסיד
4. מייצר קובץ PDF חדש עם השינויים

> **דוגמה:** אם המבחן המקורי מציג א. כל התשובות נכונות, ב. זיהוי...,  
> הגרסה המעורבלת תציג א. הרשאה, ב. שלימות... — והאות תמיד תישאר ליד התשובה הנכונה לה.

---

## הרצה מהירה

### דרישות מוקדמות

- Python 3.9 ומעלה

### התקנה

```bash
git clone https://github.com/yedi18/exam-shuffler.git
cd exam-shuffler
pip install -r requirements.txt
```

### הפעלת הממשק הגרפי (אתר)

```bash
python app.py
```

ואז פתח בדפדפן: **http://localhost:8080**

מכאן אפשר:
- לגרור קובץ PDF של מבחן
- להזין סיד (אופציונלי) — לאותו סיד תמיד יצא אותו ערבול
- להוריד את הקובץ המעורבל

### שימוש משורת הפקודה

```bash
python shuffle.py exam.pdf --seed 42 --out output.pdf
```

| פרמטר | תיאור |
|-------|-------|
| `--seed` | מספר הסיד לערבול (אופציונלי — אקראי אם לא הוזן) |
| `--out` | נתיב קובץ הפלט (אופציונלי) |
| `--dpi` | רזולוציה בפיקסלים לאינץ' — ברירת מחדל 200 |

## פורמט מבחנים נתמך

הכלי תומך במבחני PDF בעברית שבהם:
- שאלות מסומנות בפורמט **"שאלה מספר N:"**
- תשובות מסומנות באותיות **א. ב. ג. ד. ה.** בצד ימין של הדף
- הכותרת מכילה `0000` כמציין מקום לקוד הגרסה
